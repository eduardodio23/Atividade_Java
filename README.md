
🍽️ Atividade 1 — Sistema de Pedidos

A primeira atividade consiste em um sistema simples de pedidos de uma lanchonete.

O usuário pode:

Visualizar as opções disponíveis;
Escolher produtos;
Adicionar diferentes produtos ao pedido;
Acumular os valores;
Visualizar o total da compra;
Continuar adicionando produtos ou finalizar o pedido.
Conceitos praticados
Scanner
Variáveis
if / else if / else
do while
Operadores
Acumuladores
Entrada de dados pelo usuário
👥 Atividade 2 — Sistema de Métricas

A segunda atividade consiste em um sistema para cadastrar pessoas e analisar algumas informações do grupo.

O usuário pode:

Adicionar uma pessoa;
Informar idade;
Informar sexo;
Informar salário;
Exibir os resultados;
Encerrar o programa.

O sistema calcula:

Quantidade de pessoas cadastradas;
Média salarial do grupo;
Maior idade registrada;
Menor idade registrada;
Quantidade de mulheres com salário igual ou superior a R$ 5.000,00.
Conceitos praticados
Scanner
Variáveis
if / else if / else
do while
Operadores lógicos (&& e ||)
Acumuladores
Contadores
Comparações
Cálculos com dados fornecidos pelo usuário
